## Scope and implementation

After the owner confirmed I6c automatic darkness and physical wake, development
continued with the planned State page. COM6 remains the authorized USB-only
Waveshare No Touch board; no GPS or strips are connected. PCB revision/power
acceptance remains open. No new peripherals, settings or partition changes.

State adds two groups: existing GPS reception classification and a read-only
snapshot of active LED policy/transport. Intent, body enablement and alert remain
independent, including Day Mode with a system alert. The combined LED alert is
labelled `Aviso GPS / Wi-Fi`. Storage health, battery, satellite freshness and
applied brightness lack the required observations and are omitted.

Activity → Wi-Fi → State → Activity preserves wake-only first release and the
opt-in 30 s timer. Three shared LVGL containers are allocated once; buffer
9,600 bytes, pool 48 KiB, SPI 40 MHz, RGB565/swap 0 and pinned libraries remain.
Stage-3 `e` selects State. GPS demo is explicitly labelled; LED policy stays real.
See [guide](../../Platformio/Dog-RGB/docs/display-i6d.md).
