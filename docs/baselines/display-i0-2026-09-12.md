## Implemented scope

Compile-time Classic and candidate Waveshare V2 profiles preserve the existing
`pins.h` interface. Checks reject missing/conflicting profiles, reserved or
colliding external pins, Wokwi with Waveshare and unimplemented bring-up stages.
`board::begin()` handles power/backlight and optional heartbeat; both heartbeat
paths in the normal main loop use the same guarded function.

`waveshare_lcd169` reuses the application; `waveshare_lcd169_bringup` compiles
only the common entry point, board support and the stage-0 diagnostic. That
diagnostic starts before normal storage/config/GPS/LED/radio initialization,
reports identity/reset/memory/uptime/raw SYS_OUT, and leaves LCD disabled.
Late or disconnected USB monitoring is supported without waiting for a host.

The local manifest selects generic ESP32-S3, explicit 16 MiB QIO flash/8 MiB OPI
PSRAM and USB CDC. No graphics library, sensor driver, storage migration,
portal change or new power-budget default was introduced. The electrical
mapping and source provenance are in [boards.md](../../Platformio/Dog-RGB/docs/boards.md).

The firmware CI job now has four environments with separate named artifacts,
size/package/hash capture and a manifest-sensitive cache key. Host tests remain
one shared job. Other existing jobs are unchanged. YAML was parsed locally and
the matrix checked; GitHub Actions execution is not claimed.

Commands below run from `Platformio/Dog-RGB`; use the explicit executable above
when `pio` is not on PATH.

```powershell
pio --version
pio pkg install -e seeed_xiao_esp32s3
pio run -e seeed_xiao_esp32s3 -e wokwi
python -m unittest discover -s test -p "test_*.py" -v
```

Before edits: dependency resolution passed, **2/2 builds** and **131/131 host
tests** passed. Initial log files: `before-build.txt`, `before-host.txt`.

After implementation:

```powershell
pio run -e seeed_xiao_esp32s3 -e wokwi -e waveshare_lcd169 -e waveshare_lcd169_bringup
python -m unittest discover -s test -p "test_*.py" -v
```

Final results: **4/4 builds**, **134/134 host tests**. Final logs:
`final-build.txt`, `final-host.txt`. The three new test methods execute GPIO
behavior for all four build selections, exercise disconnected USB and reporting
cadence across `millis()` rollover, reject eight invalid combinations, and
check explicit memory/USB manifest configuration. Existing Wokwi assets/pin
contracts still pass; no existing assertion was removed.

`pio pkg list -e <environment>` and defined symbols from the pinned
`xtensa-esp-elf-nm -C --defined-only` were inspected for all four ELFs:

- No LVGL, Arduino_GFX, LovyanGFX or TFT_eSPI dependency is present.
- No display/LVGL symbols are present.
- Product binaries contain `gps::begin()` and no `bringup::` symbols.
- Diagnostic contains `bringup::tick()` and no `gps::`, `led_ui::`,
  `scene_runtime::`, `wifi_mgr::` or `storage::begin()` symbols.

These are software/linkage checks, not evidence of electrical behavior or RF
performance. `git diff --check` and local documentation path-link checks passed.
