# Baseline de Fase 1 — 2026-08-12

Este registro acompaña el plan de [`RGB Dog × WLED`](../analisis-wled-y-plan-implementacion.md). La implementación de software de la Fase 1 está completa; la calibración eléctrica y térmica del collar físico sigue abierta y no se sustituye con este modelo.

## Resultado

La salida LED ya tiene una frontera medible y un límite global para las dos tiras:

- `LedFrame` conserva el frame lógico RGB de los buses A/B en memoria fija;
- `LedBus` es el único módulo que conoce Adafruit NeoPixel, pines, orden GRBW y transporte;
- `rgb_to_rgbw()` centraliza la extracción de blanco usada tanto para estimar como para escribir;
- `PowerLimiter` calcula un único factor que preserva color y simetría entre buses;
- el factor baja inmediatamente ante sobrepresupuesto y recupera ocho unidades por frame para evitar bombeo visible;
- no hay asignación dinámica en el hot path.

## Modelo eléctrico implementado

La conversión conserva el comportamiento anterior:

```text
W = min(R, G, B)
R' = R - W
G' = G - W
B' = B - W
```

La estimación usa los valores enteros que realmente recibirá NeoPixel después del factor global y del brillo. Replica el caso especial de Adafruit NeoPixel donde brillo `255` no escala; los demás valores usan `(brillo + 1) / 256` con truncamiento entero.

```text
I_led_mA = ceil(sum((R'+G'+B') × rgb_channel_mA + W × white_channel_mA) / 255)
I_total_mA = base_current_mA + I_led_mA
```

Si `I_total_mA` supera el presupuesto, una búsqueda binaria selecciona la mayor escala entera `0..255` cuya estimación final queda dentro del límite. La búsqueda incluye los dos buses activos; no asigna presupuestos independientes que puedan sobrepasar el total al combinarse.

Estos valores son conservadores de arranque, no especificaciones del hardware. El presupuesto definitivo debe quedar por debajo de la capacidad continua segura de celda, protección, boost, pistas, cables y conectores, con margen térmico.

## Configuración y migración

El esquema runtime pasa de `5` a `6` y el registro binario de `1` a `2`. La migración no borra configuración del propietario:

1. se intenta decodificar el registro v6 actual;
2. si el tamaño corresponde al layout v5, se valida magic, versión, tamaño, CRC, strings y campos antiguos;
3. se conservan brillo, modos, rangos, efectos, Wi-Fi, geocerca, Day Mode y filtros GNSS;
4. los cinco campos nuevos reciben defaults conservadores;
5. se escribe una nueva generación v6 en el slot A/B inactivo y se verifica por lectura.

`GET/POST /api/config` expone `led.power`:

```json
{
  "led": {
    "brightness": 77,
    "power": {
      "enabled": true,
      "budget_ma": 1000,
      "base_current_ma": 200,
      "rgb_channel_ma": 20,
      "white_channel_ma": 20
    }
  }
}
```

La UI mantiene estos campos dentro de **Potencia LED (avanzado)**. La configuración simple sigue mostrando solo modo y brillo.

## Validación física pendiente

Antes de fijar el presupuesto final:

1. alimentar desde fuente de laboratorio con límite externo conservador;
2. medir simultáneamente corriente de celda, rail de 5 V y mínimos de 5 V/3,3 V;
3. ejecutar negro/status, primarios, blanco, amarillo, efecto típico, Show y tráfico Wi-Fi;
4. comparar lectura y `estimated_ma` durante suficiente tiempo para estabilización térmica;
5. registrar error porcentual y ajustar corriente base/perfil siempre hacia el lado conservador;
6. comprobar temperatura de celda, boost, protección, conectores, cables, XIAO y tiras;
7. repetir en el máximo brillo/presupuesto que se pretenda permitir.

La Fase 1 física se cierra cuando el modelo no subestima el consumo relevante dentro de la tolerancia acordada, ningún rail cae fuera de límites, no hay resets ni parpadeo por el factor y todos los componentes permanecen dentro de sus ratings térmicos. Hasta entonces, 1.000 mA es un default provisional y no una certificación de seguridad.

## Limitaciones conocidas

- No hay sensor de corriente, tensión, batería ni temperatura: la telemetría es un modelo.
- La corriente real de SK6812 cambia por lote, tensión y temperatura.
- El consumo base varía con GNSS, AP/STA, tráfico y eficiencia del convertidor.
- Desactivar el limitador es una opción avanzada para laboratorio; elimina el techo de software.
- La recuperación suave reduce bombeo, pero la inspección visual final debe hacerse en las tiras físicas.
