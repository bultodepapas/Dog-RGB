Dog-RGB is ESP32-S3 Arduino firmware for a smart RGBW LED dog collar. Active project: Platformio/Dog-RGB. Hardware-facing code targets Seeed XIAO ESP32-S3, EBYTE E108-GN02 GNSS over UART1 at 9600 baud, two 24-pixel SK6812 RGBW strips via Adafruit NeoPixel, Wi-Fi AP/STA portal, optional BLE read-only summary, and NVS persistence. Source structure: src/main.cpp orchestrates; gps/ owns NMEA, metrics, sessions, tracks; led/ effects/status; wifi/ radio policy; web/ synchronous WebServer API/pages; config/ validation and persistence; geofence/ home; power/ day mode; storage/ Preferences; util/ Haversine. Root tests/tools contain Playwright portal preview tests. The repository has scoped AGENTS.md under firmware and hardware but no root AGENTS.md despite their references.
